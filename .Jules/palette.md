## 2025-05-15 - Accessibility and UX micro-enhancements in Portfolio App
**Learning:** Initializing theme state within a `LaunchedEffect` in Jetpack Compose causes a visual flicker on app launch because the first composition uses the default value before the effect runs. Accessing semantics properties like `progressBarRangeInfo` and `selected` requires specific imports or `androidx.compose.ui.semantics.*`. Redundant `contentDescription` on icons near descriptive text creates unnecessary screen reader noise.
**Action:** Initialize theme state directly with the system theme value during `remember` initialization. Use `mergeDescendants = true` for custom interactive or informative components to provide a cohesive announcement. Always nullify `contentDescription` for decorative or redundant icons.
